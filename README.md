# Portfolio de Data Analytics

Repositorio personal con las prácticas y proyectos del **Curso de Data Analytics**: SQL, Python, estadística, machine learning, gobierno del dato y visualización con Excel, Power BI, Tableau y Qlik Sense.

## Sobre mí

Estudiante de DAM y especialización en Análisis de Datos, con experiencia en entornos donde la resolución de problemas, el análisis y la organización son fundamentales. Me intenesa desarrolar mi carrera trabajando con datos para encontrar patrones, generar insights y ayudar a tomar mejores decisiones.
